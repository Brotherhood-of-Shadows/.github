# Brotherhood of Shadows

Games should be played the way they were meant to be, not the bad way developers designed them.

Studios routinely bury good games under unfair mechanics, artificial grind, and locked-down formats. We write software to fix that:

- **Fairness software** — Tools and utilities that strip unfairness, tedium, and lopsided systems out of games.
- **Modding tools & content** — Extractors, reverse-engineered format tools, and resources that give players what they need to build mods and reshape games themselves.

Everything we release is built to put control back in the player's hands.
